# Output

This directory will contain reproducible analytical outputs generated by the scripts in `code/`.

Planned contents include:

- main Mundlak regression results;
- sectoral WUE model results;
- robustness and sensitivity analyses;
- diagnostic-test outputs;
- marginal-effect calculations and confidence intervals;
- intermediate tables used to produce manuscript tables and figures.

Files will be named so that they can be traced directly to the corresponding table, figure, or robustness result in the manuscript.
